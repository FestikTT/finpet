# Питомец Финни

Игра про карманные деньги для детей 7–11 лет. Сделана для хакатона «Лидеры цифровой трансформации» по заданию Департамента финансов Москвы.

Ребёнок заводит питомца, получает игровые монеты и учится ими управлять. Если потратить всё на игрушки, питомца будет нечем кормить. Умереть или заболеть питомец не может, но его настроение падает. Игра сразу показывает ошибку и учит, как её исправить.

---

## Как запустить

Вам понадобятся **Android Studio** и **JDK 17**.

1. Откройте папку проекта в Android Studio.
2. Дождитесь, пока Gradle скачает зависимости.
3. Нажмите кнопку **Run** (`Shift + F10`) на эмуляторе или телефоне с Android 8.0+.

Сборка из консоли:
```bash
# Windows
.\gradlew.bat assembleDebug

# Linux / Mac
./gradlew assembleDebug
```

Готовый файл появится здесь:  
`app/build/outputs/apk/debug/app-debug.apk`

## Как устроена игра

В приложении включен демо-режим. Все 5 игровых периодов можно пройти сразу, не дожидаясь реальных дней.

Вот основные части по ТЗ:

1. **Вход без регистрации.** Ребёнок вводит только кличку питомца и своё игровое имя. Никаких телефонов, почты и фамилий.
2. **Конструктор питомца.** 3 вида (лис, кот, панда), 4 цвета и 16 аксессуаров. Всё нарисовано вектором через Canvas, без тяжелой графики.
3. **Главный экран.** На одном экране видны баланс монет, шкалы сытости и радости, текущая цель и задание.
4. **Бюджет.** До начала периода ребёнок делит монеты на три конверта: «Надо», «Хочу» и «Коплю». Потратить больше бюджета нельзя. В конце периода игра сравнивает план с фактом.
5. **Задания.** 54 вопроса на темы бюджета, покупок и безопасности. После ответа игра сразу объясняет, почему этот выбор хороший или плохой.
6. **Магазин.** Еда и уход — обязательные траты. Игрушки и мебель — необязательные. В минус уйти нельзя. Если монет мало, игра пишет, сколько не хватает, и предлагает заработать их в квестах.
7. **Копилка.** Можно копить на самокат, игру или создать свою цель. Игра сама считает, сколько периодов осталось копить. Если снять монеты раньше времени, игра предупредит, на сколько периодов отложится покупка.
8. **Эволюция питомца.** За несколько периодов питомец растет: Малыш → Финансист → Эксперт.
9. **Сохранение.** Все данные хранятся локально в базе SQLite на телефоне. Приложение работает без интернета.
10. **Родительский раздел.** Закрыт примером на умножение. Внутри родитель видит прогресс ребёнка, может добавить домашнее задание с наградой и сбросить профиль для новой проверки.

## Стек технологий

* **Язык:** Kotlin
* **Интерфейс:** Jetpack Compose (Material 3)
* **База данных:** SQLite (встроенная, без сторонних серверов)
* **Архитектура:** MVI / Clean Architecture с реактивным StateFlow
* **Безопасность:** Ноль опасных разрешений в AndroidManifest. Нет рекламы, трекеров и реальных платежей.
